FUEL+ — PRIX AUTOMATIQUES TOUTES LES HEURES

Ajoute ces 2 nouveaux fichiers dans ton dépôt GitHub, en conservant leurs dossiers :
  .github/workflows/maj-prix.yml
  scripts/maj_carburants.py

Le ZIP contient aussi ton site complet, mais tu n'as PAS besoin de remplacer index.html ou app.js.

1) Sur GitHub > Settings > Actions > General > Workflow permissions :
   choisir "Read and write permissions", puis Save (si disponible).
2) Sur GitHub > Actions > "Actualisation des prix des carburants" :
   cliquer "Run workflow" pour lancer une première actualisation.
3) Vérifier que l'exécution est verte et que le XML a été mis à jour.
4) Vérifier que Cloudflare Pages déploie bien les commits automatiques.

Le script télécharge le ZIP officiel :
https://donnees.roulez-eco.fr/opendata/instantane
Il extrait le XML, valide son contenu et remplace le fichier dans instantane/.
L'action se lance vers xx:17 UTC chaque heure (GitHub peut avoir du retard).
En cas de panne du fournisseur, le script échoue et garde le dernier fichier valide.
Les nouveaux prix ne deviennent visibles qu'après commit et déploiement Cloudflare.
Le site ne stocke pas les données personnelles via cette fonctionnalité.
