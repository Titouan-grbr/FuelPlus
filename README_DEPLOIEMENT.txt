Fuel+ - interface mobile et profil

1. Decompressez le ZIP.
2. Placez index.html, sw.js, icon.svg, manifest.webmanifest et le dossier instantane/ a la racine de votre depot GitHub FuelPlus.
3. Attendez le deploiement Cloudflare Pages.
4. Rechargez la page (Ctrl+F5 si necessaire).

Navigation en bas sur mobile : Carte, Stations, Favoris, Garage, Profil.
Le bouton profil en haut ouvre les informations personnelles, preferences et habitudes.
Les informations du profil restent uniquement dans le navigateur local (localStorage) et ne sont ni envoyees sur un serveur ni synchronisees. Evitez les coordonnees sensibles sur les appareils partages.
